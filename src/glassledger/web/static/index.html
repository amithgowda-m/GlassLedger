📈 XIRR & Unit Accounting Methodology

• NAV per Unit: Represents the true net equity value of each virtual portfolio unit. Formulated as $\text{Total Net Assets} / \text{Issued Units}$ ($10,000$ base units).

• XIRR (Extended Internal Rate of Return): Solves $\sum \frac{C_t}{(1 + r)^{\frac{d_t - d_0}{365}}} = 0$ for irregular virtual trade cash inflows and outflows using Newton-Raphson root finding.

• Double-Entry Integrity: Every trade settled here enforces ACID constraints, solvency checks, and balanced debits == credits in the underlying financial ledger.
